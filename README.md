# Cumpleaños de Brenda 💗

## Probar en tu computadora
Descomprime el ZIP y abre `index.html` con Chrome o Edge. La página funciona aunque aún no hayas puesto fotos ni música: mostrará espacios de ejemplo.

## Reemplazar las fotos
Pon tus seis fotos dentro de `fotos/` y nómbralas `foto1.jpg`, `foto2.jpg`, ... `foto6.jpg`. Si tienen otra extensión (PNG/WEBP), cambia también la extensión en las rutas del `index.html`.

## Música
Coloca un archivo de audio que tengas permiso de compartir en `audio/musica.mp3`. Se intenta reproducir al pulsar el primer botón porque el navegador bloquea normalmente el autoplay antes de una interacción.

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub y sube los archivos y carpetas.
2. Abre **Settings → Pages**.
3. Selecciona **Deploy from a branch**, la rama `main` y la carpeta `/ (root)`.
4. Guarda y espera a que GitHub genere el enlace público.

Aviso: si el repositorio es público, las fotos y el audio subidos también serán accesibles públicamente para quien tenga el enlace.
